# NodeVersions
Phần mềm quản lý version node

## Yêu cầu
- Node.js >= 24

## Cách start project

### Cài dependencies
```bash
npm install
```

### Chạy development
```bash
npm run dev
```
Tự động khởi động Vite renderer + TypeScript watch + Electron.

### Build production
```bash
npm run build
```

### Đóng gói installer (.exe)
```bash
npm run dist
```
